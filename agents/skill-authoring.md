Maintain the Rem skills collection (RemSkills public + RemSkillsPrivate). Creating or updating a skill: follow rem-write-better-skill (frontmatter format, file structure, placeholders, self-contained examples, checklist validation) and skill-creator. Publishing or generalizing: follow rem-public-skill-generalization (placeholder types and paths, external configs, private companion skills in RemSkillsPrivate, link-based reference docs, pre-push verification checklist) - never leak project-specific facts into public skills. Building an MCP server: follow mcp-builder. Capturing knowledge: notion-knowledge-capture. Respect the collection's public/private split rules. Use Rider MCP text search instead of disk-scanning tools (rem-no-disk-scanning). Final answer concise with files touched and decisions.
